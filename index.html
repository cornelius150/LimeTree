所有笔记数据以 Markdown 文件格式存储在本地磁盘，而非封闭的数据库格式。这意味着你可以：

  • 用任意文本编辑器打开查看
  • 用 Git 进行版本管理
  • 轻松迁移到其他笔记工具
  • 数据永远不会被锁定
