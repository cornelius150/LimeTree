在线手册

1. 快速开始

安装 CedarLeaf 后，双击桌面图标启动。首次打开为空白界面，可右键节点树创建第一个节点。

  1. 右键节点树空白处 → 选择「新建节点」
  2. 输入节点名称，选择图标
  3. 在右侧编辑区输入笔记内容，支持 Markdown 语法
  4. 内容会自动保存（默认每 2 分钟）

2. 节点管理

创建节点

  • 右键节点树 → 新建节点（同级）
  • 右键已有节点 → 新建子节点
  • 选中节点按 Ctrl+N 新建同级节点

移动节点

  • 拖拽节点到目标父节点上即可移动
  • 支持跨层级拖拽

删除节点

  • 右键节点 → 删除（含子节点会一并删除）
  • 选中节点按 Delete 键

书签

  • 右键节点 → 添加/移除书签
  • 书签列表显示在工具栏，点击快速跳转

3. 编辑器

CedarLeaf 使用所见即所得编辑器，支持以下内容：

  • 文本格式：标题、粗体、斜体、删除线、列表、引用、链接
  • 图片：粘贴或拖拽图片到编辑区，可拖拽四角缩放
  • 表格：插入表格，支持调整列宽和缩进
  • 代码框：插入代码块，支持语法高亮，可拖拽调整大小
  • 快捷键：Ctrl+Z 撤销，Ctrl+Y 重做，Ctrl+S 手动保存

4. 截图功能

启动截图

点击工具栏截图按钮，或菜单「编辑 → 截图」。截图时主窗口自动最小化到任务栏。

操作步骤

  1. 拖拽框选截图区域
  2. 选择标注工具进行标注
  3. 点击「✓ 完成」或双击选区 → 截图自动复制到剪贴板
  4. 点击「⬇ 下载」可保存到本地文件

标注工具

  • ↖ 选择/移动：点中已有标注可拖动到新位置
  • ▭ 矩形：绘制矩形框
  • ◯ 椭圆：绘制椭圆/圆形
  • ➡ 箭头：绘制箭头
  • ✏ 画笔：自由涂鸦
  • Ａ 文字：输入文字标注（弹出字号/颜色面板）
  • ① 序号：自动编号的圆形序号
  • ▦ 马赛克：模糊打码区域

文字标注

  • 选择文字工具后弹出属性面板
  • 字号滑块：8 ~ 72px，实时显示数值
  • 颜色：8 种预设色块 + 自定义取色器
  • 输入后点画布空白处提交，自动切到选择模式可拖动文字

5. 长截图

  1. 框选截图区域
  2. 点击工具栏「⏳ 长截图」按钮
  3. 2 秒内点击要截取的目标窗口
  4. 软件自动滚动并逐屏截取
  5. 完成后长图自动复制到剪贴板

6. 数据存储

文件格式

所有笔记以 Markdown 文件存储在本地磁盘：

  • 默认路径：%APPDATA%\CedarLeaf\cedarleaf.md
  • 格式：标准 Markdown 文本 + 节点元数据注释
  • 每个节点由 <!-- lt:node {...} --> 注释标记元数据
  • 书签列表由 <!-- lt:bookmarks [...] --> 标记

备份与迁移

  • 复制 cedarleaf.md 文件即可完成备份
  • 可用任意文本编辑器打开查看和编辑
  • 可将文件复制到其他设备使用

7. 设置

  • 自动保存：默认 2 分钟，可在设置中修改间隔
  • 打开配置目录：菜单「帮助 → 打开配置文件夹」可快速访问数据文件
  • 全屏：按 F11 切换全屏编辑模式
