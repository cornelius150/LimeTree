功能介绍

📂 树形节点管理

  • 无限层级树形结构，支持多级子节点
  • 拖拽节点调整层级和顺序
  • 复制、粘贴、移动节点
  • 书签功能，快速访问常用笔记
  • 节点支持自定义图标和颜色标记
  • 全文搜索和替换

📝 Markdown 格式存储

  • 所有笔记以纯 Markdown 文本保存为本地 .md 文件
  • 每个节点包含元数据注释（ID、父节点、图标、颜色、时间戳）
  • 文件可直接用 VS Code、Typora 等工具打开编辑
  • 支持用 Git 进行版本管理
  • 自动保存，默认每 2 分钟保存一次（可配置）

📸 截图标注

  • 区域截图：拖拽框选任意区域
  • 标注工具：矩形、椭圆、箭头、画笔、文字、序号、马赛克
  • 文字标注支持字号调节（8~72px）和颜色选择（8 种预设 + 自定义取色）
  • 标注可移动：提交后切到选择模式，点中标注拖动到任意位置
  • 截图结果自动复制到剪贴板，可直接粘贴到笔记或聊天工具
  • 支持保存截图到本地文件

📏 长截图

  • 框选区域后点击长截图按钮
  • 自动滚动目标窗口并截取每一屏
  • 智能拼接为一张完整长图
  • 结果自动复制到剪贴板

🖼️ 富内容编辑

  • 基于 TipTap 的所见即所得编辑器
  • 图片插入：支持插入本地图片，可拖拽缩放
  • 表格：支持插入和编辑表格，可调整列宽
  • 代码框：支持代码高亮，可拖拽调整大小
  • 快捷键：支持撤销/重做（Ctrl+Z/Y）、保存（Ctrl+S）等常用操作

🔒 隐私与数据安全

  • 数据完全存储在本地磁盘，不上传任何服务器
  • 无需注册账号，无需联网即可使用
  • Markdown 文件格式开放透明，数据不会被锁定
  • 支持导出和备份，可随时迁移

⚙️ 其他功能

  • 节点排序：支持手动拖拽和自动排序
  • 主题：跟随系统主题（亮色/暗色）
  • 全屏模式：按 F11 切换全屏编辑
  • 自动保存间隔可自定义
