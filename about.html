项目简介

CedarLeaf 是一款轻量级桌面树形笔记软件，专注于帮助用户以树形结构组织和管理笔记。所有数据以 Markdown 格式存储在本地磁盘，开放透明，不会被任何平台锁定。

技术栈

  • Electron 32 - 跨平台桌面框架
  • Vue 3 - 前端 UI 框架
  • TipTap - 所见即所得编辑器
  • sql.js - 内存数据库（运行时）
  • Markdown 文件 - 数据持久化

开源协议

CedarLeaf 采用 MIT 开源协议，源代码托管在 GitHub。

你可以自由使用、修改和分发本软件，但请保留版权声明。

文件存储格式说明

CedarLeaf 不使用封闭的数据库格式存储笔记，而是将所有节点保存为一个 Markdown 文件（cedarleaf.md）。文件格式如下：

<!-- CedarLeaf Document -->
<!-- lt:bookmarks [1,3] -->

<!-- lt:node {"id":1,"parent":0,"name":"我的笔记","icon":"📔"} -->
# 我的笔记
笔记正文内容...

<!-- lt:node {"id":2,"parent":1,"name":"子节点","icon":"📄"} -->
## 子节点
子节点内容...

这种格式确保你的数据始终是可读的纯文本，可被任何 Markdown 编辑器打开。
